# Textarea

Texto libre de varias líneas; crece verticalmente.

## Qué provee quien lo usa

- Atributos de `<textarea>` (`rows`, `maxLength`, `defaultValue`).

## Reglas

- Si hay límite de caracteres, mostrar el contador en `hint` («120 de 500»).
- Usar para motivos, notas y observaciones; nunca para datos estructurados.
