# RadioGroup

Grupo de opciones excluyentes, todas visibles.

## Qué provee quien lo usa

- `legend` (la pregunta), `options` `{ value, label, description?, disabled? }`, `value`/`defaultValue`, `onChange(value)`, `name`.

## Reglas

- 2 a 5 opciones; con más, `Select`.
- Siempre una opción preseleccionada cuando hay un valor recomendado.
