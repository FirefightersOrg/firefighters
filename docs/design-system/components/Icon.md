# Icon

Ícono de trazo de 24×24, trazo 1,75px, en `currentColor`.

## Qué provee quien lo usa

- `name`: `check`, `info`, `alert`, `error`, `success`, `x`, `chevron-down`, `plus`, `search`, `inbox`, `download`, `menu`.
- `size="sm"` para 16px (`icon-sm`); por defecto 20px (`icon-md`).
- `label` si el ícono comunica algo por sí solo (se anuncia como imagen); sin `label` queda oculto para lectores de pantalla.

## Reglas

- El color lo hereda del texto: ponerlo dentro de un elemento con el token correcto.
- Para íconos que no están acá, usar Lucide (ISC) con la misma geometría.
- Nunca emoji.
