# Disclosure

Bloque plegable para información secundaria (historial, detalles técnicos, conflictos).

## Qué provee quien lo usa

- `summary` (qué contiene), `meta` (conteo o estado a la derecha), `defaultOpen`, `children`.

## Reglas

- Nunca esconder errores ni acciones obligatorias dentro.
- Basado en `<details>`: funciona sin JavaScript y con teclado.
