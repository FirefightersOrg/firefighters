# EmptyState

Lo que se muestra cuando una lista, tabla o búsqueda no tiene contenido. _Adición intencional: el repositorio muestra listas vacías sin guía._

## Qué provee quien lo usa

- `title`: qué no hay («Todavía no hay registros», «Sin resultados para «Pérez»»).
- `children`: cómo empezar o qué probar.
- `actions`: la acción que resuelve el vacío; `icon` (por defecto `inbox`; `search` para búsquedas).

## Reglas

- Diferenciar «todavía no hay» (primera vez) de «sin resultados» (filtro): en el segundo, ofrecer «Limpiar filtros».
