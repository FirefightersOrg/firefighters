## Fixes in this PR

- **Winners and prizes export** (`winners-prizes`) and sections 6b/6c of `scripts/reconcile-backup.sql`.
  Both were the last `TODO(SAN-113)`. The backups page no longer lists it as "Pendiente".
- **Offline page:** its copy used voseo ("Revisá", "intentá") and the first person. It now follows the
  rule of no voseo and impersonal forms. `offline.html` and `theme_color` in the manifest used the old
  `#2563eb`; they now use `#2350c4`, the same as `app.html`.

## Known gaps

- **SAN-139 / SAN-140:** there's no collector-coordinator role; only the five seeded roles are verified.
- **Real Supabase restore:** the restore check above is local (same cluster, separate database). The
  monthly check on Supabase (restore into a separate project) can only be done with dashboard access.
  The runbook is in `docs/backup-operations.md` and must be done and recorded before production.
- **Physical install** on an Android or iOS device was not tried; Chrome's installability criteria
  are checked automatically.
- `pnpm test:integration` only passes **from a clean DB**. On a second run without `db reset`,
  `phase-3-acceptance` fails because the seeded collector ends up linked (since #129). Reported in #50.
